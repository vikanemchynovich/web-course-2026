# Дзен-мани — лабораторная №8 (CRUD на json-server)

## Файлы

| Файл | Что в нём |
|---|---|
| `index.html` | Разметка; подключает `main.js` как ES-модуль |
| `main.js` | Точка входа: состояние, загрузка данных, обработчики событий |
| `api.js` | Все запросы к серверу: `getCategories`, `getTransactions`, `addTransaction`, `updateTransaction`, `deleteTransaction` |
| `ui.js` | Отрисовка: сводка, таблица, категории, форма, уведомления |
| `finance.js` | Расчёты без DOM и сети: сводка, сортировка, проверка формы, форматирование сумм и дат |
| `style.css` | Стили |
| `db.json` | База для json-server |

## Запуск

ES-модули не работают, если открыть `index.html` двойным кликом (адрес `file://...`):
браузер блокирует их. Страницу нужно открывать через локальный сервер.

### Вариант 1 — одной командой (проще всего)

```bash
cd task8
npx json-server --watch db.json --port 3001 --static .
```

Открыть <http://localhost:3001> — json-server отдаёт и сайт, и API.

### Вариант 2 — команда из задания + Live Server

```bash
cd task8
npx json-server --watch db.json --port 3001
```

Страницу открыть через расширение Live Server в VS Code (обычно <http://127.0.0.1:5500>).

Важно: Live Server перезагружает страницу при изменении любого файла в папке, а json-server
переписывает `db.json` после каждого добавления, правки и удаления. Чтобы страница не
перезагружалась, добавьте в настройки VS Code:

```json
"liveServer.settings.ignoreFiles": ["**/db.json"]
```

## Версии json-server

`npm install -g json-server` сейчас ставит версию **1.0.0-beta**. В ней:

- `--watch` можно не писать (файл и так отслеживается) — с ним команда тоже работает;
- `id` новых записей — случайные строки (`"FLH5ugUKjtQ"`), а не 1, 2, 3.

В классической версии **0.17.4** (`npm install -g json-server@0.17.4`) `id` — числа.
Код работает с обеими: `id` нигде не считается числом и всегда сравнивается как строка.
